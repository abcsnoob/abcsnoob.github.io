Abc's Noob Open Social

A serverless, peer-powered social network that survives censorship, disasters, and time.

What Is This?

Abc's Noob Open Social is an experimental social network where every installed app is a node and no central server exists.

"What if social communication behaved like life itself — slow, resilient, and impossible to fully destroy?"

Core Properties

  • Serverless by design — nothing to shut down
  • Cryptographic identity — no accounts, no resets
  • Offline-first — works with or without Internet
  • Peer-powered — users carry the network
  • Fork-based governance — control requires consent

What This Is Not

  • Not real-time
  • Not algorithm-driven
  • Not ad-based
  • Not engagement-optimized

Latency is acceptable. Durability is mandatory.

Technology Direction

  • Language: Go (Golang)
  • Append-only local storage
  • Content-addressed data
  • Peer-to-peer replication
  • No global clock
